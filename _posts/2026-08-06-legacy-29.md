> 计算不超过 n 且与 n 互质的正整数个数 φ(n)。

## 模板作用

计算不超过 n 且与 n 互质的正整数个数 φ(n)。

## 适用场景

欧拉定理、剩余系和互质计数问题时使用。

## 复杂度

单个 n 的时间 O(√n)，空间 O(1)。

## 使用提醒

按质因子逐次执行 res = res / p * (p - 1)；n 最后的剩余质因子别遗漏。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

const int N = 110;

typedef long long LL;

int n;

vector<int> divisors(int x){
    vector<int> primes;
    for(int i = 2; i <= x / i ; i++){
        if(x % i == 0){
            primes.push_back(i);
            while(x % i == 0) x /= i ;
        }
    }
    if(x > 1) primes.push_back(x);
    return primes;
}

int main(){
    scanf("%d",&n);
    while(n--){
        int x;
        scanf("%d",&x);
        auto primes = divisors(x);
        LL res = x;
        for(auto t: primes) res = res / t *(t - 1); //这里是大坑，不能有小数
        printf("%lld\n",res);
    }
    return 0;
}
````
