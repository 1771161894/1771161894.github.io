> 用递推或公式计算基础范围内的组合数 C(n, m)。

## 模板作用

用递推或公式计算基础范围内的组合数 C(n, m)。

## 适用场景

小范围组合计数、动态规划初始化等场景。

## 复杂度

取决于具体预处理方式，常见预处理 O(n²)。

## 使用提醒

先确认 n、m 的范围和是否需要取模，再选择杨辉三角、逆元或 Lucas 定理。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

const int N = 2010,mod = 1e9+7;

int c[N][N];
int n;

void init(){
    for(int i = 0 ; i < N ; i++){
        for(int j = 0 ; j <= i ; j++){
            if(!j) c[i][j] = 1;
            else c[i][j] = (c[i-1][j] + c[i-1][j-1]) % mod;
        }
    }
}

int main(){
    scanf("%d",&n);
    init();
    while(n--){
        int a,b;
        scanf("%d%d",&a,&b);
        printf("%d\n",c[a][b]);
    }
    return 0;

}
````
