> 根据质因数分解计算整数的约数数量。
{: .prompt-info }

## 模板作用

根据质因数分解计算整数的约数数量。

## 适用场景

需要统计某个数或若干数乘积的约数个数时使用。

## 复杂度

单个数分解约 O(√n)。

## 使用提醒

若 n = p₁^a₁p₂^a₂…，答案为 (a₁+1)(a₂+1)…；注意题目是否要求取模。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

typedef unsigned long long ULL;

const int N = 110, mod = 1e9+7;

int n;
unordered_map<int ,int > primes;

void nums_divisors(int x){
    for(int i = 2; i <= x / i ; i++){
        while(x % i ==0) x /= i , primes[i] ++;
    }
    if(x > 1) primes[x] ++;
}

int main(){
    scanf("%d",&n);
    while(n--){
        int x;
        scanf("%d",&x);
        nums_divisors(x);
    }
    ULL res = 1;
    for(auto t:primes) res = (t.second+1) * res % mod;
    printf("%d",res);
    return 0;
}
````
