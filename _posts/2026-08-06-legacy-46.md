> 用二进制 Trie 在数组中寻找异或值最大的两个数。
{: .prompt-info }

## 模板作用

用二进制 Trie 在数组中寻找异或值最大的两个数。

## 适用场景

最大异或对、按位贪心和二进制前缀匹配问题。

## 复杂度

时间 O(n × 位数)，空间 O(n × 位数)。

## 使用提醒

通常从最高位到最低位贪心选择相反位；整数位数应覆盖数据范围。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

const int N = 1e5+9, M = 31 * N;

int son[M][2],n,idx;

void insert(int x){
    int p = 0;
    for(int i = 30; i >=0 ; i--){
        int u = x >> i & 1; //从高到低遍历，记录第i位上的二进制数是多少
        if(!son[p][u]) son[p][u] =  ++ idx;
        p = son[p][u];
    }
}

int query(int x){
    int p = 0,res = 0;
    for(int i = 30; i >=0 ; i--){
        int u = x >> i & 1;
        if(son[p][!u]) res = res *2 +1,p = son[p][!u];
        else res *= 2,p = son[p][u] ;
    }
    return res;
}

int main(){
    scanf("%d",&n);
    int res = 0;
    while(n--){
        int x;
        scanf("%d",&x);
        insert(x);
        res = max(res,query(x));
    }
    printf("%d",res);
}
````
