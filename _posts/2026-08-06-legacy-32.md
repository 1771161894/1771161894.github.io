> 用快速幂求模意义下的乘法逆元。
{: .prompt-info }

## 模板作用

用快速幂求模意义下的乘法逆元。

## 适用场景

模数为质数，且需要进行模除法时使用。

## 复杂度

每次查询 O(log p)。

## 使用提醒

费马小定理要求 a 与 p 互质；不能直接用于合数模数。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

typedef long long LL;

const int N = 1e6+10;

int n;

LL qmi(int a,int b,int c){
    LL t = a;
    LL res = 1;
    while(b){
        if(b & 1) res = res * t % c;
        t = t * t % c;
        b >>= 1;
    }
    return res;
}

int main(){
    scanf("%d",&n);
    while(n--){
        int a,p;
        scanf("%d%d",&a,&p);
        LL t = qmi(a,p-2,p); // 由费马小定理得出 a^(p-1) % p = 1,故a * a^(p-2)同余于1(mod p)
        printf("%lld\n",t);
    }
    return 0;
}
````
