> 枚举到 √n，同时收集成对出现的约数。
{: .prompt-info }

## 模板作用

枚举到 √n，同时收集成对出现的约数。

## 适用场景

需要列出单个整数的全部约数时使用。

## 复杂度

时间 O(√n)，空间 O(约数个数)。

## 使用提醒

当 i * i 等于 n 时不要重复加入同一个约数；最后通常需要排序。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

const int N = 110;

int n;

vector<int> divisors(int x){
    vector<int> res;
    for(int i = 1 ; i <= x / i ; i ++){
        if(x % i == 0) {
            res.push_back(i);
            if(i * i != x)
                res.push_back(x/i);
        }
    }
    sort(res.begin(),res.end());
    return res;
}

int main(){
    scanf("%d",&n);
    while(n--){
        int x;
        scanf("%d",&x);
        vector<int> res = divisors(x);
        for(auto t : res) printf("%d ",t);
        puts("");
    }
    return 0;
}
````
