> 把字符串映射为前缀哈希，快速比较任意两个子串。

## 模板作用

把字符串映射为前缀哈希，快速比较任意两个子串。

## 适用场景

大量子串相等判断、字符串去重或模式比较时使用。

## 复杂度

预处理 O(n)，单次比较 O(1)。

## 使用提醒

下标要统一；哈希有碰撞概率，严格场景可使用双哈希。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

typedef unsigned long long ULL; // 用unsigned long long来代替字符串哈希的对2^64取模操作，溢出即为模后值

const int N = 1e5+9, P = 131; // 一般P是131 13331

int n,m;
char str[N];
ULL h[N],p[N];

ULL get(int l,int r){
    return h[r] - h[l-1] * p[r-l+1];
}

int main(){
    scanf("%d%d%s",&n,&m,str+1);
    p[0] = 1;
    for(int i = 1; i <= n ; i++){
        p[i] = p[i-1]*P;
        h[i] = h[i-1]*P + str[i];
    }
    while(m--){
        int l1,r1,l2,r2;
        scanf("%d%d%d%d",&l1,&r1,&l2,&r2);
        if(get(l1,r1) == get(l2,r2)) puts("Yes");
        else puts("No");
    }
    return 0;
}
````
