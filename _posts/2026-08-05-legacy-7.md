> 复习 C++ 自定义比较器的三种写法，并厘清 sort 与 priority_queue 对比较结果的不同理解。

**原分类难度：** 基础

## 先分清三种写法

1. **普通比较函数**：直接把函数名传给 `sort`。
2. **仿函数**：结构体或类重载 `operator()`；本质是对象，但可以像函数一样调用。
3. **Lambda 表达式**：临时使用最方便；不需要外部变量时捕获列表写 `[]`。

以 `pair<int, int>` 为例，按 `first` 升序；`first` 相同则 `second` 降序：

```cpp
bool cmp(const pair<int, int>& a, const pair<int, int>& b) {
    if (a.first != b.first) return a.first < b.first;
    return a.second > b.second;
}

struct Cmp {
    bool operator()(const pair<int, int>& a,
                    const pair<int, int>& b) const {
        if (a.first != b.first) return a.first < b.first;
        return a.second > b.second;
    }
};

auto cmpLambda = [](const pair<int, int>& a,
                    const pair<int, int>& b) {
    if (a.first != b.first) return a.first < b.first;
    return a.second > b.second;
};
```

## `sort` 中怎么传

```cpp
sort(a.begin(), a.end(), cmp);       // 普通函数
sort(a.begin(), a.end(), Cmp());     // 临时仿函数对象
sort(a.begin(), a.end(), cmpLambda); // Lambda
```

记忆：`cmp(a, b) == true` 表示 **a 应排在 b 前面**。

- `return a < b;`：升序
- `return a > b;`：降序

## `priority_queue` 的关键差异

这里模板参数需要的是**比较器类型**，所以仿函数写 `Cmp`，不要写 `Cmp()`：

```cpp
struct MinCmp {
    bool operator()(int a, int b) const {
        return a > b;
    }
};

priority_queue<int, vector<int>, MinCmp> heap;
```

Lambda 的类型没有名字，要用 `decltype`，并在构造时传入 Lambda 对象：

```cpp
auto cmp = [](int a, int b) { return a > b; };
priority_queue<int, vector<int>, decltype(cmp)> heap(cmp);
```

记忆：`priority_queue` 中 `cmp(a, b) == true` 可以理解为 **a 的优先级比 b 低，a 应往下沉**。

因此 `return a > b;` 得到小根堆。

## 速记与自测

> **sort：true 的前面排。**
> **priority_queue：true 的往下沉。**

- 只在局部用一次：优先写 Lambda。
- 需要作为模板参数或多处复用：结构体仿函数最稳。
- 比较器必须满足严格弱序，不能让同一对元素互相都“应该在前”。

## 代码

````cpp
using pii = pair<int, int>;

// sort：first 升序，second 降序
bool cmp(const pii& a, const pii& b) {
    if (a.first != b.first) return a.first < b.first;
    return a.second > b.second;
}

// priority_queue：小根堆
struct MinCmp {
    bool operator()(int a, int b) const {
        return a > b;
    }
};
priority_queue<int, vector<int>, MinCmp> heap;
````
