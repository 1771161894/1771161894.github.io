> 用模拟长除法计算大整数除以普通整数的商和余数。

## 模板作用

用模拟长除法计算大整数除以普通整数的商和余数。

## 适用场景

被除数很长、除数可放入普通整数时使用。

## 复杂度

时间 O(n)，空间 O(n)。

## 使用提醒

从最高位向最低位扫描；商的前导零需要在输出前清理。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

const int N = 1e5 +10;

vector<int> div(vector<int> &a,int b,int &r){
    vector<int> res;
    for(int i = a.size() ; i >= 0 ; i--){
        r = r * 10 + a[i];
        res.push_back(r / b);
        r %= b;
    }
    reverse(res.begin(),res.end());
    while(res.size() > 1 && res.back() == 0) res.pop_back();
    return res;
}

int main(){
    int b,r=0;
    vector<int> a,res;
    char sa[N];
    scanf("%s%d",sa,&b);
    for(int i = strlen(sa) - 1; i >= 0 ; i --) a.push_back(sa[i] - '0');
    res = div(a,b,r);
    for(int i = res.size() - 1 ; i >= 0 ; i--) printf("%d",res[i]);
    puts("");
    printf("%d",r);
}
````
