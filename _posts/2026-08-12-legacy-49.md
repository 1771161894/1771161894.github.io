# C++ 输入输出常见坑：`getline`、`ignore` 与 IO 混用

## 1. `cin >>` 后接 `getline()` 可能读到空串

```cpp
int n;
cin >> n;

string s;
getline(cin, s);
```

原因：

```cpp
cin >> n
```

读走数字后，换行符 `\n` 还留在输入缓冲区。

下一句：

```cpp
getline(cin, s);
```

会直接读到这个 `\n`，因此：

```cpp
s == ""
```

### 解决

简单情况：

```cpp
cin.ignore();
getline(cin, s);
```

更稳：

```cpp
cin.ignore(numeric_limits<streamsize>::max(), '\n');
getline(cin, s);
```

表示清空当前行剩余内容，直到换行。

---

## 2. `getline(cin >> ws, s)`

也可以写：

```cpp
getline(cin >> ws, s);
```

`ws` 会跳过前面的所有空白字符，包括：

```text
空格
换行
Tab
```

适合不需要保留行首空格的情况。

如果需要保留行首空格，不要用 `ws`，改用：

```cpp
cin.ignore(numeric_limits<streamsize>::max(), '\n');
getline(cin, s);
```

---

## 3. 为什么 `cin >>` 不怕换行？

```cpp
cin >> x;
```

会自动跳过前导空白字符，因此空格、换行、Tab 通常不会影响读取。

而：

```cpp
getline(cin, s);
```

会从当前位置一直读取到换行，因此残留的 `\n` 会直接导致读取结束。

# 4. `ios::sync_with_stdio(false)` 后不要混用 C / C++ IO

常见竞赛写法：

```cpp
ios::sync_with_stdio(false);
cin.tie(nullptr);
```

此时建议统一使用 C++ IO。

### C++ IO

```cpp
cin
cout
cerr
getline
```

### C IO

```cpp
scanf
printf
puts
getchar
putchar
```

注意：

```cpp
puts()
```

和：

```cpp
getchar()
```

也属于 C IO。

关闭同步后混用两套 IO，**输出显示顺序可能与实际执行顺序不一致**。

例如不要这样写：

```cpp
ios::sync_with_stdio(false);

cin >> x;
cout << x << '\n';
puts("debug");
```

推荐统一：

```cpp
cin >> x;
cout << x << '\n';
cout << "debug\n";
```

---

## 5. 调试时立即刷新输出

普通：

```cpp
cout << "debug\n";
```

可能暂时停留在缓冲区。

调试时可以：

```cpp
cout << "debug" << endl;
```

`endl` 相当于：

```text
换行 + flush
```

所以：

```cpp
cout << "now = " << now << endl;
```

适合观察程序实时执行情况。

正式提交时一般用：

```cpp
cout << '\n';
```

避免频繁 flush。

---

## 6. 刷题速记

```cpp
// cin >> 后接 getline
cin.ignore(numeric_limits<streamsize>::max(), '\n');
getline(cin, s);
```

或：

```cpp
getline(cin >> ws, s);
```

但 `ws` 会吃掉行首空格。

写了：

```cpp
ios::sync_with_stdio(false);
```

以后尽量只用：

```cpp
cin / cout / getline
```

不要混：

```cpp
scanf / printf / puts / getchar / putchar
```

一句话总结：

> `cin >>` 后接 `getline` 要处理残留换行；关闭 IO 同步后不要混用 C IO 和 C++ IO。
