> 枚举中转点，计算任意两点之间的最短距离。

## 模板作用

枚举中转点，计算任意两点之间的最短距离。

## 适用场景

顶点数较小、需要多次查询任意两点距离时使用。

## 复杂度

时间 O(n³)，空间 O(n²)。

## 使用提醒

最外层必须枚举中转点 k；注意无穷大不能参与普通加法。

## 代码

````cpp
//Floyd算法求多源最短路，要求不能有负环
#include<bits/stdc++.h>

using namespace std;

const int N = 210, INF = 0x3f3f3f3f;

int n,m,p;
int d[N][N];

void floyd(){
    for(int k = 1; k <= n ; k++)
        for(int i = 1; i <= n ; i++)
            for(int j = 1; j <= n ; j++)
                d[i][j] = min(d[i][j] , d[i][k]+d[k][j]); // 这里是一个动态规划
}

int main(){
    scanf("%d%d%d",&n,&m,&p);
    memset(d,0x3f,sizeof d);
    for(int i = 1 ; i <= n ; i++)
        for(int j = 1; j <= n ; j++)
            if(i == j) d[i][j] = 0; // 把对角线初始化为0,解决结点自身的负环问题

    while(m--){
        int a,b,c;
        scanf("%d%d%d",&a,&b,&c);
        d[a][b] = min(d[a][b],c); // 去重边
    }

    floyd();

    while(p--){
        int a,b;
        scanf("%d%d",&a,&b);
        if(d[a][b] > INF/2) puts("impossible");
        else printf("%d\n",d[a][b]);
    }
    return 0;
}
````
