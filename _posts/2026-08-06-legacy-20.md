> 用数组模拟竖式乘法，计算超出内置整数范围的乘积。
{: .prompt-info }

## 模板作用

用数组模拟竖式乘法，计算超出内置整数范围的乘积。

## 适用场景

大整数相乘、结果位数很长时使用。

## 复杂度

时间 O(nm)，空间 O(n + m)。

## 使用提醒

一般把低位放在数组前面，最后记得去除前导零。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

const int N = 100010;

vector<int> mul(vector<int> &a,int b){
    int t = 0;
    vector<int> res;
    for(int i = 0 ; i < a.size() || t ; i++){
        if(i < a.size()) t += a[i] * b;
        res.push_back(t % 10);
        t /= 10;
    }
    while(res.size() > 1 && res.back() == 0) res.pop_back();
    return res;
}

int main(){
    char str[N];
    int b;
    vector<int> a;
    scanf("%s%d",str,&b);
    int n = strlen(str);
    for(int i = n-1 ; i >= 0 ; i--) a.push_back(str[i] - '0');
    vector<int> res = mul(a,b);
    for(int i = res.size() - 1 ; i >= 0 ; i --) printf("%d",res[i]);
    return 0;
}
````
