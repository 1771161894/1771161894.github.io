> 通过试除判断一个整数是否为质数。

## 模板作用

通过试除判断一个整数是否为质数。

## 适用场景

查询次数不多、单个数字范围适中时使用。

## 复杂度

单次 O(√n)。

## 使用提醒

1 不是质数；循环条件建议写 i ≤ n / i 避免平方溢出。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

const int N = 110;

int n;

bool is_prime(int x){
    if(x < 2) return false;
    for(int i = 2 ; i <= x/i ; i++){
        if(x % i == 0) return false;
    }
    return true;
}

int main(){
    scanf("%d",&n);
    while(n--){
        int a;
        scanf("%d",&a);
        if(is_prime(a)) puts("Yes");
        else puts("No");
    }
    return 0;
}
````
