# Deque / 单调队列刷题心得

单调队列题不要死记“先 `pop_front`、再 `pop_back`、再入队”的固定模板。

最重要的是先定义清楚：

> **计算当前位置 `i` 的答案时，`deque` 里应该代表哪些下标。**

操作顺序应该由“当前状态的候选区间”决定。

---

## 1. 当前 `i` 属于当前窗口

例如普通滑动窗口最大值，当前窗口是：

```text
[i-k+1, i]
```

当前 `i` 本来就属于当前窗口，因此通常写成：

```text
删过期
→ 维护单调性
→ i 入队
→ 取队头得到当前答案
```

例如求滑动窗口最大值：

```cpp
while(!dq.empty() && dq.front() < i - k + 1)
    dq.pop_front();

while(!dq.empty() && a[dq.back()] <= a[i])
    dq.pop_back();

dq.push_back(i);

ans = a[dq.front()];
```

---

## 2. 当前 `i` 不能参与自己的答案

例如 P1714《切蛋糕》。

固定右端点 `i` 后：

```text
区间和 = pre[i] - pre[j]
```

其中合法的前缀和下标为：

```text
j ∈ [i-m, i-1]
```

这里不能取 `j = i`，否则：

```text
pre[i] - pre[i] = 0
```

对应长度为 0 的空区间，不合法。

因此当前 `i` 只能服务未来，通常写成：

```text
删过期
→ 计算当前答案
→ 维护单调性
→ i 入队
```

例如：

```cpp
while(!dq.empty() && dq.front() < i - m)
    dq.pop_front();

res = max(res, pre[i] - pre[dq.front()]);

while(!dq.empty() && pre[dq.back()] >= pre[i])
    dq.pop_back();

dq.push_back(i);
```

---

## 3. 单调方向怎么判断

只看你需要维护什么最值。

### 求窗口最大值

维护对应值**单调递减**，这样：

```text
队头 = 当前窗口最大值
```

通常写：

```cpp
while(!dq.empty() && a[dq.back()] <= a[i])
    dq.pop_back();
```

### 求窗口最小值

维护对应值**单调递增**，这样：

```text
队头 = 当前窗口最小值
```

通常写：

```cpp
while(!dq.empty() && a[dq.back()] >= a[i])
    dq.pop_back();
```

---

## 4. `pop_front()` 和 `pop_back()` 分别在干什么

### `pop_front()`

处理的是：

> **下标已经过期，不属于当前合法窗口。**

也就是按照“位置”淘汰。

例如：

```cpp
while(!dq.empty() && dq.front() < left)
    dq.pop_front();
```

---

### `pop_back()`

处理的是：

> **这个元素虽然还没有过期，但已经被新元素支配，以后不可能成为答案。**

也就是按照“价值”淘汰。

因此可以简单记成：

> **队头删过期，队尾删没用。**

---

## 5. 为什么 Deque 一般存下标而不是直接存值

因为我们通常同时需要两件事：

1. 判断这个元素是否已经离开窗口；
2. 根据它找到对应的值进行大小比较。

所以一般：

```cpp
deque<int> dq;
```

里面存的是下标。

然后：

```cpp
a[dq.front()]
a[dq.back()]
```

访问对应的值。

## 6. 写单调队列前先问自己

不要直接开始默模板，先确定：

1. 当前 `i` 的合法候选下标区间是什么？
2. 这个区间是否包含当前 `i`？
3. 我要维护最大值还是最小值？
4. `deque` 应该保持单调递增还是单调递减？
5. 当前 `i` 应该在计算答案之前入队，还是之后入队？

尤其是第 2 个问题最关键：

> **当前 `i` 能不能参与自己的答案？**

如果能，例如普通滑动窗口 `[i-k+1,i]`：

```text
删过期
→ 维护单调性
→ i 入队
→ 查询答案
```

如果不能，例如候选范围 `[i-m,i-1]`：

```text
删过期
→ 查询当前答案
→ 维护单调性
→ i 入队
```

---

## 7. 最重要的结论

不要死记固定的 Deque 操作顺序。

> **Deque 的操作顺序由“计算当前状态时的合法候选区间”决定，而不是由模板决定。**

以后遇到单调队列题，先在草稿上写一句：

```text
计算 i 时，dq 应该存哪些下标？
```

只要这句话定义清楚，后面的：

```text
pop_front
pop_back
查询答案
当前下标入队
```

顺序通常就会自然确定。

---

## 一句话总结

> **单调队列 = 用 `pop_front()` 删除过期候选，用 `pop_back()` 删除被支配候选，让 `dq.front()` 始终保存当前窗口所需的最优值；具体操作顺序取决于当前 `i` 是否属于自己的候选集合。**
