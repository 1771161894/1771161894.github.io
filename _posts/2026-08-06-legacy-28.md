> 通过二进制拆分指数，快速计算 a 的 b 次幂或模幂。

## 模板作用

通过二进制拆分指数，快速计算 a 的 b 次幂或模幂。

## 适用场景

幂很大、需要取模、组合数或矩阵快速幂的基础场景。

## 复杂度

时间 O(log b)，空间 O(1)。

## 使用提醒

每次平方后记得取模；乘法可能溢出时需要使用更大整数类型。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

typedef long long LL;

const int N = 1e6+10;

int n;

LL qmi(int a,int b,int c){
    LL t = a;
    LL res = 1;
    while(b){
        if(b & 1) res = res * t % c;
        t = t * t % c;
        b >>= 1;
    }
    return res;
}

int main(){
    scanf("%d",&n);
    while(n--){
        int a,b,c;
        scanf("%d%d%d",&a,&b,&c);
        LL t = qmi(a,b,c);
        printf("%lld\n",t);
    }
    return 0;
}
````
