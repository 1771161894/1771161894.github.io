> 在线性时间内筛出 1 到 n 的全部质数。

## 模板作用

在线性时间内筛出 1 到 n 的全部质数。

## 适用场景

需要批量质数、最小质因子或后续数论预处理时使用。

## 复杂度

时间 O(n)，空间 O(n)。

## 使用提醒

内层循环在 i % primes[j] == 0 时停止，保证每个合数只被最小质因子筛掉一次。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

const int N = 110 ;

int n;
bool st[N];
int cnt;
int primes[N];

void get_primes(){
    for(int i = 2 ; i <= n ; i++){
        if(!st[i]) primes[cnt ++] = i;
        for(int j = 0 ; j <= n / i ; j++){
            st[primes[j] * i] = true;
            if(i % primes[j] == 0) break;
        }
    }
}

int main(){
    scanf("%d",&n);
    get_primes();
    printf("%d",cnt);
    return 0;
}
````
