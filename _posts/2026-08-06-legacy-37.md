> 在求 gcd 的同时求出 ax + by = gcd(a, b) 的一组系数。
{: .prompt-info }

## 模板作用

在求 gcd 的同时求出 ax + by = gcd(a, b) 的一组系数。

## 适用场景

求逆元、线性同余方程和不定方程时使用。

## 复杂度

时间 O(log min(a, b))。

## 使用提醒

递归回溯时 x、y 的更新顺序不能写反；逆元存在前先检查 gcd 是否为 1。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

const int N = 1e5+10;

int exgcd(int a,int b,int &x,int &y){ // 代表当前 ax + by = gcd(a,b)
    if(!b){
        x = 1,y = 0;
        return a;
    }
    int d = exgcd(b,a%b,y,x);
    y -= a/b*x;
    return d;
}

int main(){
    int n;
    scanf("%d",&n);
    while(n--){
        int  a,b;
        scanf("%d%d",&a,&b);
        int x,y;
        exgcd(a,b,x,y);
        printf("%d %d\n",x,y);
    }
    return 0;
}
````
