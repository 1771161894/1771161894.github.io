> tuple用于多个元素的组合，也就是大于两个元素的pair

**原分类难度：** 进阶

`tuple` 可以理解为 **可以存放任意多个元素的 `pair`**。

`pair` 只能放两个元素：

```cpp
pair<int, int> p = {1, 2};
```

而 `tuple` 可以放三个、四个甚至更多元素：

```cpp
tuple<int, int, int> t1 = {1, 2, 3};
tuple<int, int, int, int> t2 = {1, 2, 3, 4};
tuple<int, string, double> t3 = {1, "Tom", 92.5};
```

## 1. 创建 `tuple`

最常见的写法：

```cpp
tuple<int, int, int> t = {1, 2, 3};
```

也可以使用：

```cpp
auto t = make_tuple(1, 2, 3);
```

竞赛中一般直接使用第一种写法即可。

---

## 2. 访问元素

可以用 `get<下标>()` 访问，下标从 `0` 开始：

```cpp
tuple<int, int, int> t = {1, 2, 3};

cout << get<0>(t) << endl; // 1
cout << get<1>(t) << endl; // 2
cout << get<2>(t) << endl; // 3
```

如果使用 C++17，更推荐结构化绑定：

```cpp
auto [a, b, c] = t;
```

此时：

```cpp
a == 1;
b == 2;
c == 3;
```

---

## 3. `tuple` 可以直接比较

`tuple` 自带比较规则，采用 **字典序比较**：

1. 先比较第一个元素；
2. 第一个相同，再比较第二个；
3. 依次向后比较。

例如：

```cpp
tuple<int, int, int> a = {1, 2, 5};
tuple<int, int, int> b = {1, 3, 1};

cout << (a < b); // true
```

因为第一项都是 `1`，继续比较第二项：

```text
2 < 3
```

所以 `a < b`。

---

## 4. 配合 `set` 使用

由于 `tuple` 自带比较规则，因此可以直接作为 `set` 的元素：

```cpp
set<tuple<int, int, int>> s;

s.insert({1, 2, 3});
s.insert({1, 2, 5});
```

判断是否存在：

```cpp
if(s.count({1, 2, 3})){
    cout << "exist" << endl;
}
```

利用 `insert()` 的返回值还能写得更简洁：

```cpp
if(s.insert({a, b, c}).second){
    // 原来不存在，插入成功
}
```

其中：

```text
.second == true   -> 原来没有这个元素
.second == false  -> 原来已经存在
```

例如在图论中去除完全重复的边：

```cpp
set<tuple<int, int, int>> hs;

for(int i = 0; i < m; i++){
    int a, b, c;
    cin >> a >> b >> c;

    if(hs.insert({a, b, c}).second){
        add(a, b, c);
    }
}
```

这样可以自动过滤完全相同的 `(起点, 终点, 边权)`。

## 5. `tuple` 默认不能直接放进 `unordered_set`

下面这种写法通常不能直接使用：

```cpp
unordered_set<tuple<int, int, int>> s;
```

因为 `unordered_set` 需要哈希函数，而标准库默认没有提供可以直接用于 `tuple` 的哈希。

如果一定要使用，需要自己定义 hash：

```cpp
struct TupleHash{
    size_t operator()(const tuple<int, int, int>& t) const{
        auto [a, b, c] = t;

        return ((size_t)a * 1000003)
             ^ ((size_t)b * 10007)
             ^ c;
    }
};

unordered_set<tuple<int, int, int>, TupleHash> s;
```

机考中如果只是为了方便去重，通常直接：

```cpp
set<tuple<int, int, int>>
```

更加省事。

---

## 6. 和 `pair` 对比

```cpp
pair<int, int> p = {1, 2};

tuple<int, int, int> t = {1, 2, 3};
```

`pair` 访问：

```cpp
p.first;
p.second;
```

`tuple` 访问：

```cpp
get<0>(t);
get<1>(t);
get<2>(t);
```

C++17 下统一可以使用结构化绑定：

```cpp
auto [x, y] = p;
auto [a, b, c] = t;
```

## 7. 机考速记

真正需要记住的基本只有这些：

```cpp
// 定义
tuple<int, int, int> t = {a, b, c};

// 解包
auto [x, y, z] = t;

// 放入 set
set<tuple<int, int, int>> s;

// 插入
s.insert({a, b, c});

// 查询
if(s.count({a, b, c})) ...

// 插入并判断是否原本不存在
if(s.insert({a, b, c}).second) ...
```

一句话总结：

> `pair` 适合两个值，`tuple` 适合临时打包多个值；`tuple` 可以直接用于 `set`，但默认不能直接用于 `unordered_set`。
