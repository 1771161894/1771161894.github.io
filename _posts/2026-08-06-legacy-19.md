> 试除法分解一个正整数的所有质因子及其指数。

## 模板作用

试除法分解一个正整数的所有质因子及其指数。

## 适用场景

需要分解单个中等范围整数时使用。

## 复杂度

时间 O(√n)，空间 O(1)。

## 使用提醒

循环条件使用 i ≤ n / i 可避免 i * i 溢出；最后剩余的大于 1 的 n 也是质因子。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

const int N = 110;

int n;

void devide(int x){
    for(int i = 2 ; i <= x / i ; i++){
        if(x % i == 0){
            int cnt = 0;
            while(x % i == 0) x /= i , cnt ++;
            printf("%d %d\n",i,cnt);
        }
    }
    if(x > 1)printf("%d 1\n",x); // 数字本身含有一个较大的质因子的情况
}

int main(){
    scanf("%d",&n);
    while(n--){
        int x;
        scanf("%d",&x);
        devide(x);
        puts("");
    }
    return 0;
}
````
