> 通过重复松弛所有边，求允许负边的单源最短路。

## 模板作用

通过重复松弛所有边，求允许负边的单源最短路。

## 适用场景

边数不大，且题目可能出现负权边时使用。

## 复杂度

时间 O(nm)，空间 O(n)。

## 使用提醒

第 n 次仍可松弛通常意味着存在从源点可达的负环；数组需要初始化为无穷大。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

const int N = 510,M = 10010;

struct Edge{
    int a,b,c;
}edge[M]; // Bellman_ford算法的边存储最自由

int n,m,k;
int dist[N];
int backup[N];

void bellman_ford(){
    memset(dist,0x3f,sizeof dist);
    dist[1] = 0;
    for(int i = 0 ;i < k ; i++){
        memcpy(backup,dist,sizeof dist); // 存个备份，以满足最多经过k条边的要求
        for(int j = 0 ; j < m ; j++){
            auto t = edge[j];
            dist[t.b] = min(dist[t.b],backup[t.a]+t.c);
        }
    }
}

int main(){
    scanf("%d%d%d",&n,&m,&k);
    for(int i = 0 ; i < m ; i++){
        int a,b,c;
        scanf("%d%d%d",&a,&b,&c);
        edge[i] = {a,b,c};
    }

    bellman_ford();

    if(dist[n] > 0x3f3f3f3f/2) puts("impossible"); // 这里所有的边都会被遍历，所以有些不可达的点可能也会被处理
    else printf("%d",dist[n]);
    return 0;
}
````
