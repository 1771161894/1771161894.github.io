> 用欧几里得算法求两个整数的最大公约数（GCD）。

## 模板作用

用欧几里得算法求两个整数的最大公约数（GCD）。

## 适用场景

需要约分、判断互质、处理整除关系，或作为扩展欧几里得算法的基础时使用。

## 复杂度

时间 O(log min(a, b))，空间 O(log min(a, b))。

## 使用提醒

输入为多个整数对；若题目只有一组数据，删去外层循环即可。

## 代码

````cpp
#include<bits/stdc++.h>

using namespace std;

const int N = 1e5+10;

int n;

int gcd(int a,int b){
    return b ? gcd(b,a%b) : a;
}

int main(){
    scanf("%d",&n);
    while(n--){
        int a,b;
        scanf("%d%d",&a,&b);
        int res = gcd(a,b);
        printf("%d\n",res);
    }
    return 0;
}
````
